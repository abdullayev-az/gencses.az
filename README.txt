# Gənc Səs — front-end prototipi

## Fayllar
- `index.html` — səhifənin strukturu və bölmələr
- `style.css` — responsive dizayn
- `script.js` — demo interaktivlik
- Bootstrap 5.3.3 və Bootstrap Icons CDN vasitəsilə yüklənir.

## Açmaq
`index.html` faylını brauzerdə aç. İnternet bağlantısı Bootstrap və Google Fonts üçün lazımdır.

## Hazır olan funksiyalar
- Dəstək kateqoriyaları və müraciət modalı
- Demo müraciət kodu yaradılması
- Nümunə kodla müraciət izləmə
- Region və maraq sahəsinə görə imkan filtri
- Region seçimi
- Müəssisə əməkdaşlıq forması
- Demo admin panel görünüşü
- Mobil və planşet uyğunlaşması

## Vacib
Bu, yalnız front-end prototipidir. Müraciət və müəssisə formaları serverə məlumat göndərmir və məlumat bazasına yazmır. İstehsal üçün backend/API, məlumat bazası, admin autentifikasiyası və rollar, server tərəfində yoxlama, giriş jurnalları, şifrələmə, məlumatların saxlanma müddəti və təsdiqlənmiş məxfilik siyasəti əlavə edilməlidir. Psixoloji və digər həssas müraciətlər üçün giriş icazələri və yönləndirmə protokolları ayrıca dizayn olunmalıdır. Statistikadakı rəqəmlər nümunədir, real göstərici kimi təqdim edilməməlidir.
